# nandalogic.com: project instructions (Claude Code)

The root site for nandalogic.com: plain HTML files, no build step. **Brand spelling: "NANDalogic"** (a play on the NAND logic gate + Josh's last name, Nanda). Use it in all page text; the domain itself stays lowercase. This file is in the public repo (since 2026-11-21, so cloud sessions get it) but **not on the live site**: `_config.yml` tells GitHub Pages to skip it. Keep secrets and private details out of it.

## Where this lives (moved out of iCloud 2026-11-21)
- On each Mac: `~/Code/nandalogic.com` (git keeps the Macs in sync). Plan: `~/Documents/1_Projects/GITHUB-PLAN.md`.
- The session-start hook pulls; `/end` commits but never pushes this repo (a push is a deploy).

- `../Sports_Bets/` and `../Design_Systems/` links resolve in `~/Code` (Sports_Bets moved there 11/23/2026).

## Hosting
- **GitHub Pages**, public repo `NANDalogic/nandalogic.com`, branch `main`, folder `/`. The `CNAME` file holds the domain; don't delete it.
- **Deploy = `git push`.** Pages rebuilds in about a minute. Pushing is a live change, so ask Josh first.
- `_config.yml` keeps `CLAUDE.md` off the live site (check `https://nandalogic.com/CLAUDE` returns 404 after changing it).
- `page.html` is served at `/page` too (no `.html` needed), so a new page is just a new file.
- **DNS** at GoDaddy (registrar + DNS only since 2026-10-27): `@` A records → 185.199.108–111.153; `www` CNAME → `nandalogic.github.io`; `bets` CNAME → `nandalogic.github.io` (separate repo `NANDalogic/bet-log`); `learn` CNAME → `nandalogic.github.io` (separate repo `NANDalogic/learn`, added 2026-11-02). Every GoDaddy DNS save asks for a text code to Josh's phone. Batch DNS changes into one save when you can.
- The old GoDaddy Website Builder site ("Launching Soon" placeholder) still exists in GoDaddy; the domain just no longer points to it.

## Pages
- `index.html`: homepage navigator (added 2026-11-02). Button cards in two groups: "Open to everyone" (Learn → learn.nandalogic.com) and "Private" with a "Sign-in required" lock tag (Bets → bets.nandalogic.com, which has its own email-code sign-in; Planner → the Notion Backlog database, which needs Josh's Notion login). The page itself is public, so the private buttons are visible but the destinations are locked. A real door lock (Cloudflare Access) is still an open idea in `../Sports_Bets/PLAN-private-sites.md`. New site → add a card to the right group.
- `assets/`: the NANDalogic design system, shared by every subdomain (since 2026-11-03). `nandalogic.css` (full) and `nandalogic-core.css` (font + tokens + header, for bets) are generated by `../Design_Systems/nandalogic/build-live.py`; don't hand-edit them. `fonts/` = self-hosted Inter (OFL license file next to it), `brand/` = EW logo + icons. **Pushing a change here restyles learn. and bets. too.**
- `planner-privacy.html`: privacy policy for the Planner capture Google OAuth app (the URL is registered in Google Auth Platform; keep it at this path). Context: `~/Code/Planner/CAPTURE.md`.
